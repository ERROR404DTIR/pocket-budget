# PocketBudget

<p align="center"><img src="assets/readme-banner.svg" alt="PocketBudget animated banner" width="100%"></p>

A clearer view of your money. Stored on your device.

## Features
- A focused, responsive interface
- No account, backend, build step, or third-party JavaScript dependency
- Data processing stays in the browser; local data uses browser storage where applicable
- Export or print options to keep control of your work

## Run it
1. Download this repository using **Code → Download ZIP** and extract it.
2. Open `index.html` in a modern browser.
3. Start using the app. No package installation is required.

Optional local server: run `python -m http.server 8000` in the project folder, then open `http://localhost:8000`.

## Notes
- Browser storage is local to the current browser profile. Clearing site data may erase saved work; use backups where available.
- Check exported files before relying on them for important work.
